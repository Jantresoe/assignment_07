This assignment was challenging because it required me to integrate multiple functions into one cohesive data pipeline, from web scraping and data cleaning to matching competitors’ products with our own. I developed a better understanding of web scraping by inspecting HTML structures, using CSS selectors to extract product names and prices, and applying Pandas to clean datasets, merge information, compare prices, and analyze pricing gaps. I also learned how to use Streamlit to turn these results into an interactive application with useful data displays and filtering features. One particularly difficult part was identifying the correct HTML elements across different competitor websites, which sometimes caused errors in the scraping and matching process. To improve, I would practice using Chrome Developer Tools to inspect website structures, write more accurate CSS selectors, and test scraping functions on smaller datasets before integrating them into the full pipeline.
